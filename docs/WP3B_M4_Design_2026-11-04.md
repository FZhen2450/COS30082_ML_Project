# M4: bounded residuals and shared frozen features

Research: Issue #12, stacked on M3 PR #11. The completed M3 findings are recorded in the adjacent M3 completion document and JSON. M3 improves H@1 to 14.6461%, but fails its disease-safety gate: 71 diseased hits versus frozen 79, and 873 false-healthy errors versus control 490. No M4 result exists yet.

The sole learning intervention is a relative residual norm cap of 0.20, compared with an unbounded control. Both retain the M3 objective, frozen official CLIP ViT-L/14, native preprocessing, 99,136 adapter parameters, original split and 323-candidate cosine scoring. The bound limits feature-direction movement to asin(0.20), approximately 11.54 degrees in exact arithmetic; it does not guarantee better predictions. The notebook tests the bound, identity initialization and gradients.

Knowledge-preserving adaptation is motivated by [WiSE-FT](https://arxiv.org/abs/2109.01903), [feature-distortion analysis](https://arxiv.org/abs/2202.10054), and [PromptSRC](https://arxiv.org/abs/2307.06948). These works motivate a hypothesis, not a claim that this implementation reproduces their methods or results.

Both arms share one immutable cache of raw frozen embeddings for the 8,000 training-source images. The cache records filenames, folds, labels, source/split/candidate/prompt fingerprints, model/preprocessing provenance, image-content hashes and tensor hashes. Loading verifies the full artifact SHA-256 and mappings. Historical frozen Top-5 predictions must match before a run is declared. Cache validity requires unchanged images, a frozen encoder, deterministic native preprocessing and no augmentation. Actual extraction time and file size are recorded when the owner runs it; speed has not been benchmarked.

The complete executable workflow is visible in `notebooks/wp3b_bounded_cached.ipynb`. Eleven execution controls default False. There is no hidden training script or automatic model download. Adapter checkpoints record the cap and cache identity and reconstruct with CPU weights-only loading. Historical M2/M3 formats and results remain intact.
