The retry uses `configs/wp1/resnet50_rtx3050.json`: ImageNet-initialized
ResNet50, separate crop and disease networks, seed 42, 3 epochs per task,
batch size 2 for both tasks, AdamW learning rate 0.0001 and weight decay 0.0001.

The serial retry uses `runs/wp1-release-20261106-b2-serial` and reuses the
same-session successful 8,000-image preflight. No model tests run alongside it.
This is a single predeclared baseline family, not a completed four-backbone
screening study. Select each component's checkpoint by seen-development
component Top-1, with the earliest epoch breaking ties. Report pair-level
development metrics afterward; do not select or tune on official tests.

From the repository root, use a new output directory:


The runner decodes the training-derived development images, trains the two

and run artifacts remain private and ignored by Git. A run is complete only when
`handoff.json` exists; `plan.json` alone is not evidence of completed training.

No official-test evaluation or teammate message is part of this runner. Share
