## Evidence, diagnosis and literature

Saved complete filename-aligned predictions independently reproduce M2 epoch-5 seen 286/1,238 and unseen 178/1,894 hits; H@1 is 13.3608% versus frozen 8.0801%. Yet diseased unseen hits fall 79/1,496 -> 16/1,496 and false-healthy errors rise 58 -> 490; healthy hits rise 101/398 -> 162/398. Unseen crop agreement improves 1,079 -> 1,427 while fitting-composition predictions rise 1,263 -> 1,600. This is an H@1 improvement with a serious subgroup regression, not uniform disease improvement. See the small aggregate evidence JSON for counts, crop breakdowns and checkpoint hashes.

M1 remains the unchanged negative factorized ablation, H@1 3.3699%. M2 epoch 1 has higher unseen Top-1 (11.2460%) and H@5 (43.1441%) than selected epoch 5 (9.3981%, 41.7819%), but lower H@1 (13.2608%). Original epoch-5 selection is correct and preserved. Epoch1 aggregate history/checkpoint exists but per-image ranks were not saved; subgroup values remain unavailable until separately guarded owner inference.

Fitting-only analysis: 958 healthy / 4,868 images; disease support min/median/max 1/7/958. Of 175 diseases, 150 occur in one fitting crop context. Saved fitting-text cosine means: same crop/different disease 0.8551; same disease/different crop 0.7346. These support a crop-confounding hypothesis but do not prove that prototype geometry, class imbalance or background alone causes the errors. The healthy share is 19.68%, so class imbalance alone is not an established explanation.

[CLIP-Adapter](https://arxiv.org/abs/2110.04544) motivates a small residual adapter rather than full backbone fine-tuning. [Learning Attention as Disentangler](https://openaccess.thecvf.com/content/CVPR2023/html/Hao_Learning_Attention_As_Disentangler_for_Compositional_Zero-Shot_Learning_CVPR_2023_paper.html) studies concept disentanglement; [Distilled Reverse Attention](https://openaccess.thecvf.com/content/ICCV2023/html/Li_Distilled_Reverse_Attention_Network_for_Open-world_Compositional_Zero-Shot_Learning_ICCV_2023_paper.html) highlights context-dependent attributes. Our much smaller conditional-loss adaptation is a testable inference from this evidence, not a reproduction of their architectures or a proven novel result. [Balanced Softmax](https://arxiv.org/abs/2007.10740) and [PromptSRC](https://arxiv.org/abs/2307.06948) were considered; adding rebalancing, teacher loss or another architecture simultaneously would obscure the first causal comparison. No new dependency is required.

## One changed objective

Keep M2's 99,136-parameter identity-initialized 768->64->768 residual visual adapter over frozen official CLIP ViT-L/14; native preprocessing and original direct text embeddings remain fixed. The base loss remains

`L_base = 0.5 CE_crop + 0.5 CE_disease + mean ||unit(adapted)-unit(frozen)||^2`.

For fitting image i, its true crop c and fitting composition p, let J(c) contain only the original fitting-composition descriptions for c. Add

`L_cond = mean_i[-log softmax_{j in J(c)}(cos(adapted_i,text_j)/0.07)[p]]`.

`L_train = L_base + lambda L_cond`, lambda=0 for paired control, 1 for intervention. All same-crop negatives are used, including healthy descriptions where fitting support exists; none are mined from validation. The 258-vector conditional bank, original IDs/pairs and hashes are checkpointed. A single-candidate crop contributes finite zero loss; the mean is over all images, including those zeros. There are 4,705 images with a same-crop negative and 2,672 diseased images with a same-crop healthy negative. Missing healthy fitting descriptions limit coverage; no held-out descriptions are added to training.

A crop cue cannot separate same-crop alternatives. The shared adapter must instead improve description discrimination while identity regularization discourages unconstrained drift. This remains a hypothesis: it can overfit crop-specific fitting diseases and may still fail transfer across crops.

Validation loss stays L_base in both arms because an unseen true pair is not a fitting conditional target. Checkpoint selection remains highest exact H@1, lower sample-weighted combined base validation loss, earliest epoch. This adds no subgroup-based checkpoint selector. Inference remains raw adapted-image versus all 323 direct text vectors, canonical float64 cosine and ascending-global-ID exact ties; there is no true-crop conditioning or healthy veto at inference.

## Protocol and bounded pilot

Source/split/candidate/prompt fingerprints remain those in the M2 evidence document and Issue #9. Use only 8,000 original training records: 4,868 fitting / 1,238 seen validation / 1,894 internally unseen validation; 55 crops, 175 diseases, 323 non-contiguous ordered IDs. No official-test fitting, tuning, inference or label use. The final shared-333-versus-separate policy remains unresolved according to the student-recorded lecturer guidance.

Exactly two fresh attempts: lambda=0 then lambda=1. Fixed seed 42, batch 8, native 224 preprocessing, no augmentation/resampling, AdamW lr=1e-4/weight_decay=1e-4, gradient clip 1, no scheduler/AMP, five epochs plus eligible epoch zero. Identical CLIP artifact, adapter initialization and sample order. The historical M2 run is a reference, not a substitute for the fresh paired control. Actual sample counts are retained; comparison refuses differing configuration, protocol or incomplete budgets.

Primary metric is H@1. A success claim additionally needs higher unseen diseased correctness, fewer false-healthy predictions than both paired control and historical M2, and recovery of at least frozen 79/1,496 diseased hits. Report H@5 and any regression. This gate qualifies the interpretation; it does not change primary selection. Report crop/disease agreement, all unseen per-pair counts, healthy/diseased groups, fitting preference, tomato/cassava, paired correctness, time and peak memory. One seed supports only an exploratory development finding, not significance or final-test generalization. This development set has informed the hypothesis; avoid repeated opportunistic tuning.
