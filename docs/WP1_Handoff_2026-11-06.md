## Fitting and evaluation provenance

Only the original training source was used: 4,868 fitting / 1,238 seen development /
1,894 internally unseen development images, with 323 ordered global candidates
in both evaluation folds. Exact ordered membership is reconciled with WP2/WP3.
All 8,000 training-source images passed decoding. No official-test inference was run.

- Seed: 42. AdamW, learning rate 0.0001, weight decay 0.0001, batch size 2,
  three epochs per task; all network parameters trainable.
- Initialization: `ResNet50_Weights.IMAGENET1K_V2`.
- Evaluation transform: RGB; shorter side resized to 232; 224 x 224 center crop;
  bilinear interpolation; antialias enabled; ImageNet mean [0.485, 0.456, 0.406]
  and standard deviation [0.229, 0.224, 0.225]. No evaluation augmentation.
- Fitting augmentation: horizontal and vertical flips, affine rotation up to
  18 degrees, translation up to 5%, scale 0.95–1.05, then native preprocessing.
- Environment: Python 3.13.13, torch 2.7.1+cu118,
  torchvision 0.22.1+cu118; NVIDIA GeForce RTX 3050 Laptop GPU.
  Use `configs/wp1/requirements_cuda118.txt` in a separate environment. The current
  checkpoint loader requires the exact recorded torchvision version.
- Base commit: `439764618093e22e68e936ab93f9ff3dd5bf1a51`; local additions were present
  (`code_dirty=true`). Exact training source hashes are recorded in `handoff.json`.
  The WP1 core is identical across the inspected main/WP1/WP2/WP3/GUI branches.
